SERVER LUA:
─────────────
-- Create legendary item
local item = Game.createItem(2400, 1)
item:setRarity(3)  -- Legendary
player:addItem(item)

-- Random rarity loot
function assignRandomRarity(item)
    local roll = math.random(100)
    if roll > 95 then return 4      -- 5% Unique
    elseif roll > 85 then return 3  -- 10% Legendary
    elseif roll > 70 then return 2  -- 15% Rare
    elseif roll > 50 then return 1  -- 20% Uncommon
    else return 0 end               -- 50% Common
end

Network Overhead:
  ▪ Per item: +1 byte
  ▪ 100 items: +100 bytes (~0.1 KB)
  ▪ Impact: Negligible

Database Overhead:
  ▪ Stored in attributes BLOB
  ▪ ~10 bytes per item
  ▪ Impact: Minimal

Client Performance:
  ▪ Shader compilation: One-time on load
  ▪ Rendering: GPU accelerated
  ▪ 100+ items: < 5% FPS impact
  ▪ Recommended: Modern GPU with shader support

Memory Usage:
  ▪ Server: +1 byte per item instance
  ▪ Client: +1 byte per item instance + shader cache
  ▪ Total: < 1 MB for 10,000 items
