# Yennefer — History

## Project: TibiaCore
C++ server based on TFS (The Forgotten Server). Builds with CMake/vcpkg.

## Key Source Files
- `server/src/spells.cpp/h` — spell loading, execution
- `server/src/vocation.cpp/h` — vocation definitions
- `server/src/player.cpp/h` — player logic
- `server/src/combat.cpp/h` — combat formulas
